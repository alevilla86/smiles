# Leishmania Activity Predictor

A machine learning application that predicts anti-leishmanial activity of chemical compounds using SMILES notation. Developed by Master's students from Universidad CENFOTEC in collaboration with Universidad de Salamanca's Department of Pharmaceutical Sciences.

## Features

- Predict activity of compounds against Leishmania parasites (L. donovani, L. major, L. infantum, L. mexicana, L. braziliensis)
- Two prediction models: Random Forest and Semi-Supervised VAE
- Web interface for easy predictions
- Model versioning with timestamps and accuracy tracking

## Installation

```bash
# Clone the repository
git clone https://github.com/your-repo/smiles.git
cd smiles

# Create virtual environment
python3 -m venv venv
source venv/bin/activate  # On Windows: venv\Scripts\activate

# Install dependencies
pip install -r requirements.txt
```

## Running the Application

```bash
# Activate virtual environment
source venv/bin/activate

# Run the Streamlit app
streamlit run main.py
```

The app will open at http://localhost:8501. You can:
1. Select a trained model from the dropdown
2. Enter one or more SMILES strings (one per line)
3. Click "Predecir actividad" to get predictions

A probability > 0.5 indicates potential activity against Leishmania.

## Training Models

### Random Forest Model

The Random Forest model uses Morgan fingerprints (radius=2, 2048 bits) to predict activity.

**Data sources:**
- Active compounds fetched from ChEMBL database (IC50 < 10 µM against L. donovani)
- Manually curated benzimidazole compounds from literature
- Random inactive compounds sampled from ChEMBL

**To train:**

```bash
# Option 1: Use existing data from txt files (fast)
python leishmania_donovani_activity_trainer.py --use-existing

# Option 2: Prepare fresh data from ChEMBL (slow, requires external_data/chembl_35.sdf)
# Download SDF from: https://ftp.ebi.ac.uk/pub/databases/chembl/ChEMBLdb/latest/
python leishmania_donovani_activity_trainer.py --from-scratch
```

**Output:**
- Model saved to `models/leishmania_donovani_rf_{timestamp}_acc{accuracy}.pkl`
- Training data saved to `training_data/l_donovani_ACTIVE.txt` and `training_data/l_donovani_NOT_ACTIVE.txt` (when using `--from-scratch`)

### VAE Model (Semi-Supervised)

The VAE model uses an autoencoder to learn latent representations, then trains a classifier on the latent space.

**Architecture:**
- Autoencoder: 2048 → 512 → 256 (latent) → 512 → 2048
- Classifier: 256 → 64 → 1

**To train:**

```bash
# Requires training_data/l_donovani_ACTIVE.txt and training_data/l_donovani_NOT_ACTIVE.txt
# (generated by the RF trainer or manually created)

python leishmania_semi_supervised.py
```

**Output:**
- Autoencoder: `models/leishmania_donovani_vae_ae_{timestamp}_acc{accuracy}.pth`
- Classifier: `models/leishmania_donovani_vae_clf_{timestamp}_acc{accuracy}.pth`

## Training Pipeline Overview

```
┌─────────────────────────────────────────────────────────────────┐
│                     DATA COLLECTION                              │
├─────────────────────────────────────────────────────────────────┤
│  ChEMBL API ──► Active compounds (IC50 < 10µM vs L. donovani)   │
│  Literature ──► Manual benzimidazole compounds (active/inactive)│
│  ChEMBL SDF ──► Random inactive compounds (balanced sampling)   │
└─────────────────────────────────────────────────────────────────┘
                              │
                              ▼
┌─────────────────────────────────────────────────────────────────┐
│                   FEATURE EXTRACTION                             │
├─────────────────────────────────────────────────────────────────┤
│  SMILES ──► RDKit ──► Morgan Fingerprints (2048 bits)           │
└─────────────────────────────────────────────────────────────────┘
                              │
                              ▼
┌─────────────────────────────────────────────────────────────────┐
│                      MODEL TRAINING                              │
├─────────────────────────────────────────────────────────────────┤
│  Option A: Random Forest (500 trees)                            │
│  Option B: VAE Autoencoder + Classifier                         │
│                                                                  │
│  Train/Test Split: 80/20 (stratified)                           │
└─────────────────────────────────────────────────────────────────┘
                              │
                              ▼
┌─────────────────────────────────────────────────────────────────┐
│                    MODEL SAVING                                  │
├─────────────────────────────────────────────────────────────────┤
│  Filename: {model_name}_{YYYY-MM-DD_HH-MM-SS}_acc{accuracy}.ext │
│  Example:  leishmania_donovani_rf_2025-01-22_14-30-45_acc0.95.pkl│
└─────────────────────────────────────────────────────────────────┘
```

## Project Structure

```

├── predictors.py                    # Prediction interface (RF & VAE)
├── model_utils.py                   # Model saving/loading utilities

```
